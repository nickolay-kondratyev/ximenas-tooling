# Colab Setup — Running the Scripts

There's nothing to install or set up. You only need the links from the script author.

## Every run
1. Open the notebook link (bookmark it). It always opens the latest version.
2. Fill in the form fields (e.g. the input folder).
3. **Runtime → Run all**.
4. Approve the prompts when asked:
   - **"Warning: This notebook was not authored by Google"**: click **Run anyway**.
   - **"Connect to Google Drive"**: allow it (needed to read your files and save results).

Use the link each time instead of saving a copy to Drive. A saved copy won't get updates.

## If something goes wrong
Send the script author a screenshot of the error.
